# 常滑水野家 歴史サイト

## 1. 目的

常滑水野家の由緒、主要人物、歴史的エピソード、伝来の史料を、史料館・記念館のような落ち着いた雰囲気で紹介する1ページ構成の公式サイト試作品です。

外部サービスに依存しない静的サイトのため、パソコン内での確認やGitHub Pagesでの公開がしやすい構成です。

## 2. 構成

- 和紙色、墨色、濃紺、金色、朱色を使った和モダンデザイン
- パソコン・スマートフォン両対応
- ヘッダーメニューから各章へ移動
- スクロールに合わせた穏やかなフェードイン表示
- 家紋画像をトップと「家紋と由緒」に掲載

## 3. ファイル一覧

```text
常滑水野家_歴史サイト/
├─ index.html          サイト本文
├─ styles.css         色・文字・レイアウト

   ├─ chita-route.svg              海上交通の概念図
   ├─ tokoname-castle-site.jpg     常滑城跡（ご当家撮影）
   └─ kansei-mizuno-morinobu.jpg   『寛政重脩諸家譜』掲載画像
```

## 4. 画像ファイルの置き場所

家紋画像は、常滑水野家ご当家に伝来する品をご当家がスマートフォンで撮影・提供したものです。`images` フォルダー内に `mizuno-crest.jpg` という名前で置いています。画像を差し替える場合も、同じファイル名にするとHTMLの変更は不要です。

『寛政重脩諸家譜』の画像は、国立国会図書館デジタルコレクションがPDM（著作権による制限がない資料）として公開する画像を使用し、サイト上に出典を表示しています。

## 5. 実行方法

1. `常滑水野家_歴史サイト` フォルダーを開きます。
2. `index.html` をダブルクリックします。
3. EdgeやChromeなどのブラウザでサイトが表示されます。

特別なアプリの導入や設定は不要です。

## 6. 公開前に確認すべき史実

次の項目は断定を避けて記載しています。公開前に、伝来史料や研究資料との照合をおすすめします。

- 常滑城の築城年代
- 水野守隆の代数
- 水野守信の正確な石高
- 京都・嵯峨での隠棲年数
- 千利休が守隆を「目利き」と認めたとする逸話
- 家紋の正式名称
- 明智光秀との関係の詳細
- 各伝来文書の正式名称、年代、所蔵状況
- 掲載文に対応する出典情報

## 8. GitHub Pagesでの公開手順

1. GitHubで新しい公開用リポジトリを作ります。
2. このフォルダー内の全ファイルを、フォルダー構成を保ったまま登録します。
3. GitHubのリポジトリ画面で `Settings` を開きます。
4. 左側の `Pages` を開きます。
5. `Build and deployment` の公開元を `Deploy from a branch` にします。
6. ブランチは `main`、フォルダーは `/(root)` を選び、`Save` を押します。
7. 数分後に表示される公開URLを開いて確認します。

公開前には、家紋画像の公開許可、文章、出典、個人情報の有無を必ず確認してください。
